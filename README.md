# Simon Says Game

A browser-based memory game built using HTML, CSS, and JavaScript. The game generates a sequence of colors that the player must remember and reproduce correctly. Each successful round increases the difficulty by adding a new color to the sequence.

## Features

* Keyboard-based game start
* Random color sequence generation
* Interactive button controls
* Visual feedback for game and user actions
* Level progression
* Sequence validation
* Game-over detection
* Automatic game reset

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Play

1. Open the game in a web browser.
2. Press any key to start the game.
3. Observe the color that flashes.
4. Click the corresponding button.
5. In each new level, remember the previous sequence and the newly added color.
6. Repeat the complete sequence correctly to progress.
7. Selecting the wrong color ends the game.

### Using VS Code

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click `simonGame.html`.
4. Select **Open with Live Server**.

## Game Logic

The game uses two arrays to manage the gameplay:

* `gameSeq` stores the sequence generated by the game.
* `userSeq` stores the sequence entered by the player.

At each level, a random color is added to `gameSeq`. The player's input is then compared with the generated sequence.

If the player's sequence is correct, the game moves to the next level. If the player selects the wrong color, the game ends and the current level is displayed as the score.
